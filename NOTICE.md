# Project notice

`nordvpn-wg-merlin` is an unofficial community project for generating and managing NordVPN/NordLynx WireGuard client configuration on Asuswrt-Merlin.

## Upstream projects and references

This project intentionally draws on the behavior, ideas, and documented workflows of these upstream projects:

- **Deano86/NordConverter** — https://github.com/Deano86/NordConverter
- **caleb9/asuswrt-merlin-nordvpn-wg-updater** — https://github.com/caleb9/asuswrt-merlin-nordvpn-wg-updater
- The Merlin updater also references **sfiorini/NordVPN-Wireguard**.
